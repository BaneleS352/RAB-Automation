How monitoring works

  • Live feed — GET /rab/live polls Jira directly every 5s (project = JIRA_PROJECT_KEY ORDER BY updated DESC), no DB sync needed. Replaces manual sync as primary.
  • Webhook — every jira:issue_created / jira:issue_updated (and now any event with an issue) is upserted: summary + validation_result + status. Approval state is preserved if already tracked.
  • Manual sync — POST /rab/sync still available as backfill for DB audit trail (approvals, validation). Live feed shows Jira truth; sync materializes it to DB.
  • Demo Lab — now creates real Jira tickets when Use real Jira tickets is checked (requires JIRA_BASE_URL + creds); otherwise stub. See Demo Lab.
