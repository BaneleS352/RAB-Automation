How monitoring works

  • Webhook — every jira:issue_created / jira:issue_updated (and now any event with an issue) is upserted: summary + validation_result + status. Approval state is preserved if already tracked.
  • Sync — POST /rab/sync (JSON) or POST /dashboard/sync (UI) fetches project = JIRA_PROJECT_KEY ORDER BY updated DESC via GET /rest/api/3/search/jql and upserts every issue. Works for issues created via UI, API, CSV import, automation — regardless of webhook history.
  • Demo — Demo Lab still seeds synthetic issues (pending SDL/SDM, validation failed, aging) for pipeline preview without Jira.
